Setting up Minecraft 1.20.1

The Fighters Guild Launcher installs the modpack on top of a vanilla 1.20.1 install, so you need to create that installation in the official Minecraft Launcher first. Follow the steps below before running the Fighters Guild installer.

1

Install the official Minecraft Launcher

Grab it from minecraft.net/en-us/download. You need the "Windows Legacy" launcher, found at the very bottom of that page — not the Microsoft Store version. Install it and sign in.

2

Open the Java Edition tab

Launch the official Minecraft Launcher and select Minecraft: Java Edition from the sidebar on the left.

3

Go to Installations

Along the top of the Java Edition page, click the Installations tab.

4

Create a new installation

Click New installation.

5

Name it and pick version 1.20.1

Give the installation a name (e.g. "Minecraft 1.20.1"), then open the Version dropdown and choose release 1.20.1. Click Install.

6

Launch it once

Select your new 1.20.1 installation and hit Play at least once to finish downloading it. Once you see the main menu, you're ready to install the Fighters Guild Launcher from the Download tab.
